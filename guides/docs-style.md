# Markdown

One `#` per file, and headings step down a level at a time. Sentence case.

Fence every code block with its language. Shell blocks carry no `$` prompt, and output goes in a block of its own.

Dates are `YYYY-MM-DD`.

Links within a directory are relative. Links elsewhere in the repository start at its root. Reference-style links keep
the prose readable when a URL is long.

Tables are for data with two dimensions. One dimension is a list.

Wrap prose at 120 characters. Tables and links are exempt.

Do not repeat what another file says. Link to it.

Keep a fact close to where it is needed. A rule about a directory belongs in that directory, not in an index of it or a
changelog entry about it.
