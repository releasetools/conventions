# AI-assisted contributions

Use whatever tools you like. You are the author of every line you send.

Disclose it. A commit written with an agent carries a `Co-Authored-By:` trailer and the harness session trailer, and
those stay in the history. The trailer is the disclosure.

Read the change before you open the pull request. If you cannot say why a line is there, it is not ready.

Answer review comments yourself. A generated reply ends the conversation and the pull request closes with it.

Size is the other half. A large generated change, a repository-wide search and replace, or a lint-only sweep costs more
to review than it returns. Open an issue and agree the change is wanted first. Without that, expect it closed with a
link here.

One more: fix the whole file, not the single typo you noticed in it.
